# OPD Dashboard

## Description

The OPD (Outpatient Department) Dashboard is a comprehensive React-based web application designed to streamline patient management in outpatient settings. It provides an intuitive interface for healthcare professionals to manage patient data, appointments, and various statistics efficiently.

## Features

- Patient list with detailed information
- Advanced filtering capabilities (by doctor, date range)
- Real-time statistics display
- Tabbed interface for different patient categories (New, Nurse Seen, Doctor Visited, All Appointments)
- Modal view for detailed patient information
- Excel export functionality for patient data
- Responsive design for various screen sizes

## Technologies Used

- React
- TypeScript
- Ant Design (UI Framework)
- Context API (for state management)
- Day.js (for date manipulation)
- XLSX (for Excel export)
